# Stage 1: Console App (Parallel Arrays)

The initial procedural version of the BurgerShop application. All order data is stored in memory using six synchronized parallel arrays inside a single class.

## Concepts Demonstrated
- Procedural programming in Java
- Parallel arrays (`IntOrderId`, `StrOrderId`, `CusId`, `CusName`, `BurgerCount`, `OrderSat`)
- Manual array resizing via helper methods
- Console menu navigation, input validation, and bubble sort for ranking customers

## Files
- `BurgerShop.java` — Complete console application and entry point.

## How to Run
```bash
javac BurgerShop.java
java BurgerShop
